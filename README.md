# Embedded C Conventions

面向嵌入式 C 开发的 Cursor Skill，覆盖代码可读性、接口契约、整数与数据表示安全、并发、内存和实时性，以及构建验证。规则旨在帮助评审和实现，不替代项目约定、芯片手册或适用的安全标准。

## 文件

- `SKILL.md`：完整规范和代码审查清单，是规则的权威来源。
- `QUICK_REFERENCE.md`：日常速查。
- `LAYERING_AND_FUNCTION_TABLE.md`：架构分层与分发结构选择示例。
- `INDEX.md`：文件导航与关键原则。

## 使用

将技能目录放在 Cursor 可识别的 skills 路径，然后在对话中调用：

```text
/embedded-c-conventions
请按规范检查这个模块，重点关注整数边界、ISR 共享状态和错误路径。
```

编写或审查时先尊重代码库现有风格、编译器和目标约束。规范中的示例用于说明思路，不应不加验证地复制到目标固件。

## 适用原则

- 对公共 API 按调用契约提供必要说明；简单且自解释的声明无需重复注释。
- ISR/前台共享对象默认使用 `volatile`，并另行处理原子性、互斥、顺序和 DMA 一致性。
- 用定宽类型表达有明确宽度的数据；显式验证整数运算、窄化转换、缓冲边界和协议表示。
- 明确任务栈、堆策略、ISR/关键路径预算及其验证方式。
- 根据可读性、穷举性和扩展需求选择 `switch` 或函数表，不将函数表作为通用替代。
- 结合工具链告警、静态分析、测试和目标板/HIL 验证。

规则冲突时以 `SKILL.md` 为准；架构文档中的抽象和示例需按项目实际需求取舍。
